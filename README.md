# SVG Image Site

This GitHub Pages site displays `image.svg` when someone visits the website.

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html` and `image.svg` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)`, then save.
6. Wait for GitHub Pages to publish and open the URL shown on the Pages settings screen.
